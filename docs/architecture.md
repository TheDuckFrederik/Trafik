# Trafik Architecture Skeleton

This repository contains the final design documentation for the Trafik family of pedal-loop routing systems.

## Scope

- No Arduino or microcontroller logic
- Hardware-only final designs
- Three product variants:
  - Single Lane Trafik
  - 2 Lane Trafik
  - 4 Lane Trafik

## Documentation goals

- Define the physical layout for each variant
- Define control behavior for each variant
- Define LED and indicator logic for each variant
- Define bill of materials with vendor and price comparisons

## Status

This file is a skeleton only. Final design details should be added in the variant-specific documents.
